# 🦴 骨灵驱魔 AR（Bone Exorcism AR）

宝可梦GO 式 AR 骨学闯关游戏。用摄像头识别人体 → 3D 骨骼模型覆盖上身 → 5 块骨头被恶灵黑雾吞噬 → 查看手中骨、像扔精灵球一样甩向对应位置 → 黑雾全消即驱魔成功。

## 玩法流程

1. **扫描**：镜头对准被附身者，点击「开始驱魔」→ 自动识别人体轮廓（MediaPipe Pose），锁定目标
2. **附身**：白色骷髅覆盖在真人身上，随机 **5 块骨头**被黑雾吞噬（黑球+紫色粒子+彩色光环），同时 **300 秒倒计时**开始——被附身者 HP 随剩余时间下降
3. **查看**：点击底部骨袋里的骨头，3D 旋转查看形态，确认是什么骨头（含解剖学提示）
4. **抛掷**：按住底部金色骨球，像扔精灵球一样向上甩出，骨块沿抛物线飞向目标位置
5. **归位**：扔准了 → 黑雾爆散、骨头归位金光闪烁；扔偏了 → 提示偏差百分比，骨头回到骨袋
6. **通关**：5 块黑雾全消 → 驱魔成功，记录驱魔时长（localStorage 保存历史记录+最佳成绩）

## 运行方法

```bash
cd AR骨骼驱魔
python -m http.server 8765
```

- 电脑测试：浏览器打开 `http://localhost:8765`（需摄像头；无摄像头可点封面「演示模式」或直接访问 `/?demo=1`）
- 手机实测：需要 HTTPS 才能调用摄像头 —— 用 ngrok 转发：`ngrok http 8765`，手机打开 ngrok 生成的 https 地址

## 技术栈

| 组件 | 说明 |
|------|------|
| Three.js 0.170 | 3D 渲染（importmap CDN） |
| MediaPipe Pose | 人体 33 关键点识别（unpkg，jsdelivr 兜底） |
| skeleton.glb | BodyParts3D 真实解剖骨骼模型（201 块骨，CC BY-SA），来自 BodyExplorer |
| WebAudio | 合成音效（抛掷/命中/胜利/失败），无外部音频文件 |

## 关键技术点

### 骨骼对齐（AR 核心）
- MediaPipe 归一化坐标 → 屏幕 NDC（cover 裁剪修正 + 前置镜像翻转）→ z=-1 深度平面
- 肩中点/髋中点/脚踝 → 身高估算（肩髋距 ×3.6）→ 模型缩放 + 脚底对齐 + 平滑跟随（lerp）
- **BodyParts3D 坐标坑**：模型 X=左右、Y=前后（-Y 面朝）、Z=上下。用 `rotation.order='XZY'` + `x=-90°` + `z=180°` 转正（肩宽水平、面部朝镜头、不镜像）
- 按 `R` 键旋转模型朝向校准（存 localStorage）

### 抛掷系统
- 按住骨球拖动 → 速度向量 → 落点 = 目标位置 + 甩动偏移（速度越大偏越多）
- 二次贝塞尔抛物线飞行 0.9s，命中判定 = 落点与目标骨头屏幕投影距离 < 0.14 NDC
- 目标在屏幕外时：落点 clamp 到边缘 + 边缘箭头提示方向，转动镜头让目标入画

### 黑雾特效
- 缺失骨网格隐藏，原位生成：黑色半透明球 + 紫色粒子（Points 旋转浮动）+ 彩色光环
- 命中：粒子爆散飞溅 + 骨头金色闪光 + 光环膨胀消失
- ⚠️ 教训：`PointsMaterial.size` 是世界单位、不随父节点缩放 —— 必须用绝对世界值

## 已知限制 / v2 计划

- **单人检测**：MediaPipe Pose 经典 API 仅单人。多人画面"随机选一人"需要 PoseLandmarker（multi-pose）或额外人体检测，v2 实现
- 骨骼对齐为整体缩放+跟随，不做逐骨骼姿态匹配（人侧身时模型仍正面）
- 缺失骨从 18 块教学骨池随机 5 块（额骨/下颌骨/寰椎/胸骨/锁骨/肱骨/股骨/髌骨等）

## 教学应用

- 每块缺失骨带解剖学提示（"寰椎：无椎体，承环形托颅"）
- 抛掷前必须查看骨形态确认身份 → 强化骨名-形态-位置记忆
- 适合系统解剖学骨学章节的课堂互动 / 课后复习
